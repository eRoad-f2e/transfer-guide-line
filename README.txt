安全下载指南静态页面

部署到 Cloudflare Pages：
1. 登录 Cloudflare Dashboard。
2. 进入 Workers & Pages，创建 Pages 项目。
3. 选择 Upload assets。
4. 上传 download-guide.zip，或直接上传本文件夹。
5. 部署完成后即可获得 pages.dev 地址。

页面下载按钮不会直接跳转。
用户点击按钮后，页面会显示目标 GitHub 地址；用户确认后，新页面才会打开。

下载来源：
- CC Switch: https://github.com/farion1231/cc-switch/releases
- OpenAI Codex: https://github.com/openai/codex/releases

页面不托管安装包，不需要服务器，也不收集用户数据。
